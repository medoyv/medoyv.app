# HTTPS-хостинг Medoyv.App через Cloudflare Pages

GitHub-репозиторий `medoyv/medoyv.app` остаётся приватным. Cloudflare Pages умеет собирать сайт из приватного GitHub-репозитория. Сам сайт закрыт отдельным паролем: пока в Cloudflare не задан секрет `SITE_PASSWORD`, Worker возвращает `503` и не выдаёт каталог.

## Что должно быть в корне GitHub-репозитория

- `Medoyv.App-deploy.zip`
- `cloudflare-pages-build.sh`
- `cloudflare-worker.js`

В ZIP находятся сайт и его значки, без исходных IPA и папки `tools`.

## Создание проекта

1. В Cloudflare откройте **Workers & Pages → Create application → Pages → Connect to Git**.
2. Авторизуйте GitHub-приложение Cloudflare только для приватного репозитория `medoyv/medoyv.app`.
3. Выберите репозиторий и укажите:

   - Production branch: `main`
   - Framework preset: `None`
   - Build command: `bash cloudflare-pages-build.sh`
   - Build output directory: `public`
   - Root directory: оставить пустым

4. Создайте проект. Первая сборка без секрета покажет страницу `503`; это ожидаемо и не раскрывает сайт.
5. В проекте откройте **Settings → Variables and Secrets → Add**. Добавьте `SITE_PASSWORD` как **Secret**, только для Production. Задайте длинный случайный пароль не короче 12 символов и сохраните его у себя. Не отправляйте пароль в GitHub или в чат.
6. Повторно запустите последнюю сборку в **Deployments → Retry deployment**. После успешной сборки Cloudflare выдаст HTTPS-адрес вида `https://<имя-проекта>.pages.dev`.
7. Откройте адрес в приватном окне: он должен показать форму входа. После входа каталог загрузится. Передайте пароль только тем людям, которым нужен доступ.

Секрет добавляется после создания проекта, потому что Cloudflare сначала должен создать настройки Pages. До его добавления сайт закрыт ответом `503`. В Preview-среде секрет не задавайте: предпросмотры останутся закрытыми.

## Добавление на iPhone

Откройте HTTPS-адрес в Safari, войдите по паролю, нажмите **Поделиться → На экран Домой**, включите **Открывать как веб-приложение** и выберите **Добавить**. Это устанавливает значок PWA-каталога. Нативные IPA-кнопки останутся отключёнными, пока приложения не будут подписаны и подготовлены издателем для разрешённого способа распространения.

## Обновления

Каждый новый commit в ветку `main` запускает сборку Cloudflare. Пароль хранится только в разделе Secrets Cloudflare и не попадает в GitHub. Если нужно сменить код доступа, измените секрет `SITE_PASSWORD` и повторно разверните Production.
